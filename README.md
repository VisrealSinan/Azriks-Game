# Azriks Game

Early character asset development for a gothic exploration game.

## Character concepts

The first pass proposes **Visreal Sinan** as the street explorer and **Azrik** as a compact winged companion. These are review concepts, not game-ready sprites, rigged models, or animation atlases.
